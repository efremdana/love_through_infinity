## О новелле

Даня приходит в себя после аварийного выхода из анабиоза на экспедиционном ковчеге «Альтаир». До прибытия к Элион-5 остаётся 92 года. Остальные пассажиры спят, корабельный ИИ ГЕЯ не отвечает, а привычные инженерные объяснения постепенно перестают сходиться.

Герой исследует корабль, пытается наладить жизнь в изоляции и замечает странности в собственных воспоминаниях. Среди спящих пассажиров — Карина, чьё имя почему-то кажется знакомым.

Повествование ведётся от первого лица: наблюдения инженера, самоирония и внутренние монологи передают состояние героя. В мир вплетены личные отсылки, знакомые места и воспоминания. Визуальный ориентир — аниме, холодные оттенки корабля и тёплые акценты в жилых пространствах; среди референсов — *Spy × Family* и *Passengers*.

### Где остановилась разработка

В [game/script.rpy](game/script.rpy) после выбора занятий выполняется блок `after_choice`, затем — `return`. На этом текущая последовательность прохождения заканчивается. Выбранные занятия сохраняются в список, но ещё не запускают соответствующие сцены.

Дальнейшие эпизоды первой части уже написаны как литературный черновик в комментариях: занятия, длительная изоляция, записи Карины и моральный выбор. Этот текст нужно адаптировать в реплики, переходы и связанные сцены Ren’Py.

У двух завершающих сцен (`wake_her` и `wait_wake`) указаны отсутствующие изображения `bg cryo_hall_night` и `bg cryo_hall_morning`. Перед подключением сцен потребуются соответствующие фоны или замена ссылок на существующие.

## Запуск из исходников

### Требования

- Git — для получения исходников.
- Настроенный доступ к GitHub по SSH — для команды клонирования ниже.
- [Ren’Py SDK](https://www.renpy.org/) версии **8.4 или новее**. Текущий код выбора занятий использует синтаксис f-строк Python 3.12; этот Python включён в движок [начиная с Ren’Py 8.4](https://www.renpy.org/doc/html/changelog.html#python-3-12).

Конкретная проверенная версия SDK пока не зафиксирована. Требование 8.4+ основано на синтаксисе исходников и не заменяет проверку совместимости всей игры. Отдельно устанавливать Python или пакеты через `pip` для проекта не требуется.

### Получение проекта

Для новой локальной копии:

```sh
git clone --branch master git@github.com:efremdana/love_through_infinity.git visual_novel
cd visual_novel
```

Ветка `main` сейчас содержит только первоначальный README. Для работы с игрой нужна **`master`**. Если репозиторий уже клонирован и эта ветка выбрана, повторное клонирование не требуется.

### Открытие в Ren’Py Launcher

1. Скачайте и распакуйте SDK, затем откройте Ren’Py Launcher.
2. В настройках Launcher укажите каталог проектов — **родительскую папку репозитория**. Например, для `projects/visual_novel/game` каталог проектов — `projects`.
3. Обновите список проектов и выберите `visual_novel`. Папка `game` должна оставаться внутри корня проекта.
4. Выполните **Check Script (Lint)** / проверку сценария, чтобы увидеть ошибки и отсутствующие ресурсы.
5. Нажмите **Launch Project** / запуск проекта.

Подробнее о Launcher и проверке сценария — в [официальном руководстве Ren’Py](https://www.renpy.org/doc/html/quickstart.html).

## Структура проекта

```text
visual_novel/
├── game/
│   ├── script.rpy       # Сценарий, персонажи, выборы и литературные черновики
│   ├── screens.rpy      # Диалоги, меню, сохранения и панель ship_logs
│   ├── gui.rpy          # Размеры интерфейса, цвета и шрифты
│   ├── options.rpy      # Название, версия, переходы и настройки сборки
│   ├── images/          # Фоны и спрайты персонажей
│   ├── gui/             # Графические элементы интерфейса
│   ├── fonts/           # Дополнительные шрифты
│   ├── tl/              # Файлы перевода интерфейса Ren’Py
│   └── libs/            # Каталог для сторонних библиотек
├── old/                 # Старые варианты изображений
├── old-game/            # Архив скомпилированных сценариев
├── project.json         # Настройки проекта для Launcher
├── .gitignore           # Исключения для сохранений, кэша и служебных файлов
└── README.md
```

Рабочие исходники находятся в `game/`. В `script.rpy` точка входа — `start`, исследование начинается с `start_explore`, первая часть — с `part_one`, выбор занятий — с `choice_occupation`.

Файлы изображений именуются по правилам Ren’Py: например, `bg cryoroom.PNG` используется как `scene bg cryoroom`, а `danya normal.png` — как `show danya normal`. При добавлении ресурсов важно согласовывать имена файлов и обращения к ним в сценарии.
