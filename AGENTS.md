# Правило локальных коммитов

Пользователь установил это правило для чата Codex `01a16e90-7062-7aa0-b256-ef0e0d8984ba`.

- После каждого завершённого изменения файлов репозитория в этом чате выполняй подходящую проверку и создавай локальный Git-коммит до итогового ответа. Правило распространяется и на документацию; отдельное подтверждение для коммита не требуется.
- Включай в коммит только изменения, относящиеся к текущему поручению. Не добавляй посторонние правки пользователя.
- В итоговом ответе указывай короткий хеш созданного коммита. Если коммит не удалось создать, явно сообщай об этом.
- Отправляй коммиты на GitHub только по отдельной просьбе пользователя.
